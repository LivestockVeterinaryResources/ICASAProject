Red dashed arrows mark the places where a file is not written by the pipeline and has to be put in place by hand.

✕ Inputs the pipeline does not produce

  • shinyMorbidityParameters/data/deads_all.rds — a hand-anonymized one-off copied from DataStep2_Anonymous/external/. No script writes it to the app folder, and by design it is not wired into one.
  • ShinyExportsPredict/data/lots_with_dof_morb_mort_rail.rds — CreateFilesForShinyOutcomes_V2.R writes this file to DataStep3_Anonymous/ and shinyLotLevelDiseaseOutcomes/, never to the Econ app folder. It is copied across by hand.
  • ShinyExportsPredict/dashboard_payload.rds — written by Amrine/Predict V3.Rmd, which MasterDataProcessing_Anonymous.R never calls. Rerunning the master pipeline does not refresh the Econ app's predictions.
  • ShinyMetrics_Anonymous/get_expected_doses.csv — no script in the repo writes it; it is maintained by hand.
  • ShinyMetrics_Anonymous/df_wrangle_lot_filtered_with_wt_out.rds — the pipeline writes df_wrangle_lot_filtered.rds (no _with_wt_out) to this folder. The file the app actually reads corresponds to DataStep2_Anonymous/df_wrangle_lots_filtered_with_wt_out.rds, copied in and renamed by hand.
The ICASA → DataStep2_Anonymous step is an intentional break in the chain: it anonymizes the original feedyard data before anything is published. Everything downstream of that store — including all three apps — works only on anonymized data. Every repo, script, and data-file name shown was read directly from the project sources.
